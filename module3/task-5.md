# Задание №5: Принт-сервер CUPS на HQ-SRV и PDF-принтер на HQ-CLI

В данном задании на сервере центрального офиса (**HQ-SRV**) развёртывается сервер печати **CUPS** (Common UNIX Printing System), создаётся и публикуется в локальную сеть виртуальный принтер с выводом документов в формат PDF.

На рабочей станции **HQ-CLI** выполняется подключение опубликованного сетевого принтера и назначение его принтером по умолчанию для всех пользователей системы.

> [!IMPORTANT] Где выполнять
> 1. **HQ-SRV** — установка CUPS и модуля CUPS-PDF, настройка общего доступа к сервису печати, добавление принтера.
> 2. **HQ-CLI** — обнаружение, подключение принтера по протоколу IPP и назначение принтером по умолчанию.

---

## 1. Теоретическая справка: компоненты подсистемы печати CUPS

* **CUPS (Common UNIX Printing System)** — стандартная модульная система печати для Unix-подобных операционных систем, использующая сетевой протокол **IPP** (Internet Printing Protocol, порт TCP 631).
* **CUPS-PDF** — виртуальный драйвер печати, преобразующий очередь печати PostScript в файлы документов PDF и сохраняющий их в специальный каталог (по умолчанию `~/PDF` или `/var/spool/cups-pdf/`).
* **Утилиты командной строки**:
  * `lpadmin` — управление принтерами (добавление, настройка опций, публикация);
  * `lpoptions` — выбор принтера по умолчанию и пользовательских настроек печати;
  * `lpstat` — просмотр статуса принтеров и очередей;
  * `lp` / `lpr` — отправка документа в печать.

## 2. Памятка по работе в Vim

::: tip Памятка по работе в Vim
* **Вход в режим редактирования**: нажмите клавишу `i`.
* **Выход в командный режим**: нажмите `Esc`.
* **Сохранить и выйти**: введите `:wq` и нажмите `Enter` (или `:q!` для отмены и выхода без сохранения).
:::

## 3. Настройка сервера печати CUPS на сервере HQ-SRV

Выполните действия под пользователем `root` на сервере **HQ-SRV**:

### Шаг 1. Установка пакетов CUPS и CUPS-PDF

```bash
apt-get update && apt-get install cups cups-pdf -y
```

---

### Шаг 2. Разрешение удалённого доступа к CUPS

Открываем файл конфигурации `/etc/cups/cupsd.conf` в редакторе `vim`:

```bash
vim /etc/cups/cupsd.conf
```

1. Находим директиву `Listen localhost:631` и заменяем её на прослушивание всех интерфейсов:
```text
Port 631
```

2. В секции `<Location />` разрешаем доступ из локальной сети офиса:
```text
<Location />
  Order allow,deny
  Allow 192.168.0.0/16
  Allow localhost
</Location>
```

3. В секции `<Location /admin>` разрешаем администрирование:
```text
<Location /admin>
  Order allow,deny
  Allow 192.168.0.0/16
  Allow localhost
</Location>
```

Сохраняем файл (`Esc` → `:wq` → `Enter`).

Перезапускаем службу CUPS:
```bash
systemctl enable --now cups
systemctl restart cups
```

---

### Шаг 3. Добавление и публикация виртуального PDF-принтера

Создаём виртуальный принтер с именем **`PDF-Printer`**:

```bash
# Добавляем принтер с драйвером CUPS-PDF и включаем его (-E):
lpadmin -p PDF-Printer -v cups-pdf:/ -E -m raw

# Публикуем принтер в общий доступ:
lpadmin -p PDF-Printer -o printer-is-shared=true

# Принимаем задания на печать:
cupsaccept PDF-Printer
cupsenable PDF-Printer
```

Проверяем локальный статус созданного принтера:
```bash
lpstat -p PDF-Printer
```

---

## 4. Настройка клиента печати на рабочей станции HQ-CLI

Переходим на клиентскую рабочую станцию **HQ-CLI** под пользователем `root`:

### Шаг 1. Установка клиентских утилит CUPS
```bash
apt-get update && apt-get install cups-client -y
```

---

### Шаг 2. Подключение сетевого принтера с сервера HQ-SRV

Подключаем удалённый принтер по протоколу IPP (IP-адрес сервера HQ-SRV — `192.168.1.10`):

```bash
lpadmin -p PDF-Printer -v ipp://192.168.1.10:631/printers/PDF-Printer -E -m raw
```

---

### Шаг 3. Назначение принтера по умолчанию

Назначаем `PDF-Printer` принтером по умолчанию для всей системы:

```bash
lpadmin -d PDF-Printer
lpoptions -d PDF-Printer
```

---

## 5. Проверка печати

1. **Проверяем принтер по умолчанию**:
   ```bash
   lpstat -d
   ```
   В выводе должна отображаться строка:
   ```text
   system default destination: PDF-Printer
   ```

2. **Проверяем статус и доступность**:
   ```bash
   lpstat -p
   ```

3. **Отправляем пробное задание на печать**:
   ```bash
   echo "Тестовая печать на виртуальный PDF-принтер от имени HQ-CLI" | lp
   ```
   Задание успешно отправляется в очередь печати без ошибок!
