# Быстрый старт

Добро пожаловать в **Wiki Site**! Этот проект построен на базе [VitePress](https://vitepress.dev/) — современного генератора статических сайтов документации на базе **Vite** и **Vue 3**.

::: tip Совет
VitePress компилирует ваши `.md` файлы в ультрабыстрые статические HTML-страницы с гидратацией на клиенте.
:::

## Требования

Для запуска и разработки вам понадобятся:
- **Node.js** версии 18+ (рекомендуется 20+ или 22+)
- Пакетный менеджер: **npm**, **pnpm** или **yarn**

## Команды управления

Запуск локального сервера разработки:

```bash
npm run dev
```

Сервер запустится по адресу `http://localhost:5173` с поддержкой горячей перезагрузки (HMR). Любые правки файлов Markdown мгновенно отображаются в браузере.

### Сборка проекта

Для сборки production-версии выполните:

```bash
npm run build
```

Собранные статические файлы будут сохранены в директорию `.vitepress/dist/`.

### Предпросмотр сборки

```bash
npm run preview
```

## Структура проекта

```text
wiki-site/
├── .vitepress/
│   ├── config.mts       # Конфигурация (меню, сайдбар, заголовок, поиск)
│   └── theme/
│       ├── index.ts     # Точка входа кастомной темы
│       └── custom.css   # Стили, цвета и шрифты
├── guide/               # Раздел документации
│   ├── getting-started.md
│   ├── architecture.md
│   └── ...
├── kb/                  # База знаний
│   ├── overview.md
│   └── ...
├── public/              # Статические ассеты (картинки, лого)
├── index.md             # Главная страница
└── package.json
```
