# Создание страниц и разметка Markdown

VitePress расширяет классический Markdown мощными возможностями для технической документации.

## Блоки уведомлений (Admonitions)

::: info Информация
Полезная справочная информация для пользователя.
:::

::: tip Совет
Рекомендация или практический совет.
:::

::: warning Предупреждение
Обратите внимание перед выполнением действия.
:::

::: danger Опасность
Критическое предупреждение о возможных сбоях или потере данных.
:::

## Подсветка кода с номерами строк

```typescript:line-numbers
// Пример TypeScript кода
interface UserProfile {
  id: string
  name: string
  isAdmin: boolean
}

function greet(user: UserProfile): string {
  return `Привет, ${user.name}!`
}
```
