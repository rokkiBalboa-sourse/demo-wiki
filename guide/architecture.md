# Архитектура и принципы работы

VitePress объединяет в себе простоту статических генераторов и мощь Vue SPA (Single Page Application).

## Как это работает

1. **Каждый `.md` файл — это страница**: Имя файла и путь формируют конечный URL (например, `guide/architecture.md` -> `/guide/architecture`).
2. **Прекомпиляция в Vue SFC**: Страницы Markdown компилируются в компоненты Vue. Это позволяет вставлять реактивные компоненты прямо в текст.
3. **SSG (Static Site Generation)**: На этапе `build` каждая страница рендерится в чистый статический HTML. Это обеспечивает идеальное SEO и сверхбыструю первую загрузку.
4. **Клиентская гидратация**: После загрузки страницы включается легковесный Vue-рантайм, превращая сайт в SPA для мгновенных переходов без перезагрузки браузера.
