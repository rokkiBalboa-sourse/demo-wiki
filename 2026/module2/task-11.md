# Задание №11: Установка Яндекс Браузера на HQ-CLI

В данном задании на графическую рабочую станцию центрального офиса (**HQ-CLI**) устанавливается современный веб-браузер **«Яндекс Браузер»** (`yandex-browser-stable`).

Браузер используется сотрудниками организации в качестве основного рабочего веб-обозревателя для доступа к внутренним корпоративным порталам (`web.au-team.irpo`, `docker.au-team.irpo`) и ресурсам глобальной сети Интернет.

> [!IMPORTANT] Место выполнения
> Установка выполняется под пользователем `root` на рабочей станции **HQ-CLI** (`hq-cli.au-team.irpo`).

---

## 1. Теоретическая справка: Яндекс Браузер в ALT Linux

**Яндекс Браузер (Yandex Browser)** — производительный кроссплатформенный браузер на базе движка Chromium:
* В дистрибутивах ALT Linux официальный стабильный выпуск поставляется в репозиториях под именем пакета **`yandex-browser-stable`**.
* Браузер автоматически интегрируется в системное графическое окружение пользователя (XFCE / MATE): создаётся файл ярлыка запуска `.desktop` в категории **«Интернет»** меню приложений и регистрируются MIME-типы веб-страниц.
* Поддерживает встроенные алгоритмы отечественной криптографии (ГОСТ) для работы с государственными и корпоративными веб-ресурсами.

---

## 2. Пошаговая установка на рабочей станции HQ-CLI

Открываем терминал на машине **HQ-CLI** и переходим в режим суперпользователя `root` (`su -`):

### Шаг 1. Обновление списков пакетов и установка

```bash
apt-get update && apt-get install yandex-browser-stable -y
```

**Что делают параметры:**
* `apt-get update` — актуализирует локальный индекс доступных пакетов с внешнего репозитория ALT Linux.
* `apt-get install yandex-browser-stable -y` — скачивает и устанавливает RPM-пакет браузера со всеми зависимостями без запроса интерактивного подтверждения.

---

### Шаг 2. Проверка успешности установки

Выполняем проверку установленного RPM-пакета в базе данных системы:

```bash
# 1. Проверяем наличие установленного пакета в системе
rpm -qa | grep yandex-browser
```

Пример корректного вывода:
```text
yandex-browser-stable-24.7.1.1120-1.x86_64
```

Убеждаемся, что исполняемый бинарный файл зарегистрирован в переменной `$PATH`:
```bash
# 2. Проверяем путь и версию браузера
which yandex-browser-stable
yandex-browser-stable --version
```

Вывод:
```text
/usr/bin/yandex-browser-stable
Yandex 24.7.1.1120 (64-bit)
```

## 3. Запуск и фиксация в экзаменационном отчёте

### Запуск из графического интерфейса (GUI)
1. На рабочем столе перейдите в **Меню приложений** (в левом верхнем или нижнем углу).
2. Откройте категорию **Интернет** (Сеть).
3. Нажмите на пункт **Yandex Browser** (Яндекс Браузер).

В открывшемся браузере можно сразу протестировать доступ к корпоративным сайтам, настроенным в предыдущих заданиях:
* `http://web.au-team.irpo/` — корпоративный портал LAMP (с паролем `WEB` / `P@ssw0rd`).
* `http://docker.au-team.irpo/` — приложение `tespapp` в Docker.
