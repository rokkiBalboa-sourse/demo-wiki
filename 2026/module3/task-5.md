# Задание №5: Настройка принт-сервера CUPS

::: tip 📺 Видео-разбор задания
Видео-разбор выполнения задания доступен по ссылке: [https://docker.sudostudy.dev/s/BTRAdw9Ewsczk7d](https://docker.sudostudy.dev/s/BTRAdw9Ewsczk7d)
:::

В данном задании на сервере центрального офиса (**HQ-SRV**) настраивается служба печати **CUPS** и модуль виртуального PDF-принтера **cups-pdf**. 

В конфигурационном файле разрешается удалённый доступ к принтерам и администрированию, после чего на клиентской машине **HQ-CLI** через графическую панель параметров печати выполняется поиск и подключение опубликованного сетевого принтера.

> [!IMPORTANT] Где выполнять
> 1. **HQ-SRV** — установка CUPS и CUPS-PDF, правка `cupsd.conf`, запуск службы.
> 2. **HQ-CLI** — добавление сетевого принтера через графическое меню параметров печати.

---

## 1. Памятка по работе в Vim

::: tip Памятка по работе в Vim
* **Вход в режим редактирования**: нажмите клавишу `i`.
* **Выход в командный режим**: нажмите `Esc`.
* **Сохранить и выйти**: введите `:wq` и нажмите `Enter` (или `:q!` для отмены и выхода без сохранения).
:::

---

## 2. Настройка принт-сервера на HQ-SRV

Выполните команды под пользователем `root` на сервере **HQ-SRV**:

### Шаг 1. Установка пакетов CUPS и CUPS-PDF

```bash
apt-get update && apt-get install cups cups-pdf -y
```

---

### Шаг 2. Редактирование конфигурации /etc/cups/cupsd.conf

Открываем конфигурационный файл в редакторе `vim`:

```bash
vim /etc/cups/cupsd.conf
```

1. Находим директиву `Listen` (по умолчанию `Listen localhost:631`) и заменяем её на IP-адрес сервера:
```text
# Only listen for connections from the local machine.
Listen 192.168.1.10:631
```

2. В блоках `<Location />`, `<Location /admin>` и `<Location /admin/conf>` добавляем директиву **`Allow all`**:

```text
<Location />
  Order allow,deny
  Allow all
</Location>

<Location /admin>
  Order allow,deny
  Allow all
</Location>

<Location /admin/conf>
  AuthType Default
  Require user @SYSTEM
  Order allow,deny
  Allow all
</Location>
```

Сохраняем файл (`Esc` → `:wq` → `Enter`).

---

### Шаг 3. Запуск и проверка службы CUPS

Включаем автозапуск и перезапускаем сервис:

```bash
systemctl enable --now cups
systemctl restart cups
```

Проверяем, что порт `631` успешно слушается на интерфейсе `192.168.1.10`:

```bash
ss -ltnp4 | grep 631
```

Пример успешного вывода:
```text
LISTEN 0 128 192.168.1.10:631 0.0.0.0:* users:(("cupsd",pid=1234,fd=7))
```

---

## 3. Подключение принтера на клиенте HQ-CLI

Перейдите в графический интерфейс (GUI) на рабочей станции **HQ-CLI**:

1. Откройте **Меню** → **Параметры печати** (или «Настройка принтеров»).
2. Если в списке уже есть старый принтер — **удаляем его**.
3. Нажимаем кнопку **«Добавить»** (или «+») для добавления нового принтера.
4. В левом списке выбираем **«Сетевой принтер»** → **«Поиск сетевого принтера»**.
5. В поле адреса хоста вводим IP-адрес сервера HQ-SRV: **`192.168.1.10`** и нажимаем поиск.
6. При запросе аутентификации нажимаем **«Отмена»** (отменяем вход).
7. Выбираем найденный принтер из появившегося списка (виртуальный PDF-принтер).
8. На всех последующих шагах мастера нажимаем **«Далее»** (используем стандартные предложенные параметры по умолчанию) и в конце **«Применить»**.
9. Принтер успешно добавлен и готов к печати!
