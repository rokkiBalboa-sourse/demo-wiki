## Спецификация и требования заданий

### 1. Настройка контроллера домена Samba DC на сервере BR-SRV
* Введите в созданный домен клиентскую машину **`HQ-CLI`**;
* Создайте 5 пользователей для офиса HQ: имена пользователей формата `hquser№` (`hquser1`, `hquser2`, `hquser3`, `hquser4`, `hquser5`);
* **Политика паролей**:
  * Минимальная длина пароля: **8 символов**;
  * Блокировка учётной записи после **5 неудачных попыток** входа;
* Создайте группу **`hq`**, введите в группу созданных пользователей;
* Убедитесь, что пользователи группы `hq` имеют право аутентифицироваться на `HQ-CLI`;
* Пользователи группы `hq` должны иметь возможность повышать привилегии через `sudo` для выполнения ограниченного набора команд: **`cat`**, **`grep`**, **`id`**. Запускать любые другие команды с повышенными привилегиями пользователи группы права не имеют.

### 2. Конфигурирование дискового массива RAID 0 на HQ-SRV
* При помощи двух подключенных к серверу дополнительных дисков размером **1 Гб** сконфигурируйте дисковый массив уровня **0**;
* Имя устройства — **`/dev/md0`**, при необходимости конфигурация массива размещается в файле **`/etc/mdadm.conf`**;
* Создайте и отформатируйте раздел, в качестве файловой системы используйте **`ext4`**;
* Обеспечьте автоматическое монтирование в папку **`/raid`**.

### 3. Сервер сетевой файловой системы (NFS) на HQ-SRV
* В качестве папки общего доступа выберите **`/raid/nfs`**, доступ для чтения и записи исключительно для сети в сторону `HQ-CLI` (`192.168.200.0/28`);
* На `HQ-CLI` настройте постоянное автомонтирование в папку **`/mnt/nfs`** через `/etc/fstab`;
* Основные параметры сервера отметьте в отчёте.
