# Задание №2: Файловое хранилище RAID 0 на сервере HQ-SRV

::: tip 📺 Видео-разбор задания
*В процессе разработки*
:::

В данном задании настраивается высокопроизводительный дисковый массив уровня **RAID 0** (`stripe`) с помощью утилит `parted` и `mdadm` на сервере главного офиса **HQ-SRV**.

---

## Требования задания:
* При помощи двух подключенных к серверу дополнительных дисков размером **1 Гб** сконфигурировать дисковый массив уровня **0**;
* Имя блочного устройства — **`/dev/md0`**, конфигурацию массива зафиксировать в файле **`/etc/mdadm.conf`**;
* Создать и отформатировать раздел, в качестве файловой системы использовать **`ext4`**;
* Обеспечить автоматическое монтирование массива в каталог **`/raid`** при загрузке системы.

::: info 📍 Место выполнения
Все действия выполняются под пользователем **`root`** на сервере **HQ-SRV** (`hq-srv.au-team.irpo`).
:::

---

## Шаг 1. Проверка обнаруженных накопителей

Перед разметкой убедитесь, что гипервизор передал виртуальной машине два дополнительных диска (обычно `/dev/sdb` и `/dev/sdc` объёмом по 1G):

```bash
lsblk
```

**Пример корректного вывода:**
```text
NAME   MAJ:MIN RM SIZE RO TYPE MOUNTPOINTS
sda      8:0    0  10G  0 disk 
sdb      8:16   0   1G  0 disk 
sdc      8:32   0   1G  0 disk
sdd      8:18   0   1G  0 disk
```

![Проверка дисков lsblk](/images/2027/m2-t2-lsblk.png)

---

## Шаг 2. Разметка дисков через parted

Для работы в массиве на каждом диске создаётся таблица разделов `msdos` (MBR), раздел на весь объем диска с выравниванием `1MiB` и флагом `raid on`.

Запускаем интерактивную утилиту `parted` для первого диска:
```bash
parted /dev/sdb
```

В консоли `(parted)` последовательно вводим команды:
```text
mklabel msdos
mkpart primary 1MiB 100%
set 1 raid on
print
select /dev/sdc
mklabel msdos
mkpart primary 1MiB 100%
set 1 raid on
print
quit
```

![Разметка дисков в parted](/images/2027/m2-t2-parted.png)

#### 🔍 Разбор команд parted:
* **`mklabel msdos`** — создаёт классическую таблицу разделов MBR.
* **`mkpart primary 1MiB 100%`** — создаёт основной раздел (`primary`), начиная с отступа в 1 мегабайт (для правильного выравнивания секторов) и занимающий 100% объема диска.
* **`set 1 raid on`** — выставляет на раздел №1 специальный флаг `raid` (тип раздела `0xfd Linux RAID autodetect`).
* **`print`** — отображает текущую таблицу разделов для визуального контроля.
* **`select /dev/sdc`** — переключает контекст утилиты `parted` на второй накопитель `/dev/sdc` без необходимости выхода.
* **`quit`** — сохраняет изменения в таблицу разделов и завершает работу утилиты.

> *После завершения повторно выполните `lsblk`: под дисками `sdb` и `sdc` появятся разделы `sdb1` и `sdc1` типа `part`.*

---

## Шаг 3. Создание RAID-массива уровня 0

Объединяем созданные разделы `/dev/sdb1` и `/dev/sdc1` в единое логическое устройство `/dev/md0`:

```bash
mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/sdb1 /dev/sdc1
```

![Создание массива mdadm](/images/2027/m2-t2-mdadm-create.png)

#### 🔍 Разбор параметров:
* **`--create /dev/md0`** — команда на создание нового логического RAID-устройства с именем `/dev/md0`.
* **`--level=0`** — уровень массива (RAID 0, чередование полос / *stripe*).
* **`--raid-devices=2`** — количество активных дисков/разделов в массиве.
* **`/dev/sdb1 /dev/sdc1`** — перечень входящих физических разделов.

::: warning ⚠️ Подтверждение создания
Если утилита выведет предупреждение о том, что разделы могут содержать остаточные метаданные или старые сигнатуры файловых систем (`Continue creating array?`), подтвердите операцию, введя <kbd>y</kbd> и нажав <kbd>Enter</kbd>.
:::

---

## Шаг 4. Фиксация конфигурации массива в /etc/mdadm.conf

Чтобы массив корректно и однозначно собирался при перезагрузке операционной системы, сканируем его метаданные (включая уникальный UUID) и сохраняем в файл конфигурации:

```bash
# Дописываем информацию о массиве в конфигурационный файл:
mdadm --detail --scan >> /etc/mdadm.conf

# Проверяем сформированную запись:
mdadm --detail --scan
```

**Пример корректного вывода:**
```text
ARRAY /dev/md0 metadata=1.2 name=hq-srv:0 UUID=3a1b2c3d:4e5f6a7b:8c9d0e1f:2a3b4c5d
```

![Сохранение конфигурации mdadm.conf](/images/2027/m2-t2-mdadm-scan.png)

## Шаг 5. Форматирование в файловую систему ext4

Создаём файловую систему `ext4` на созданном блочном устройстве `/dev/md0`:

```bash
mkfs.ext4 /dev/md0
```

![Форматирование mkfs.ext4](/images/2027/m2-t2-mkfs-ext4.png)

---

## Шаг 6. Настройка точки монтирования и fstab

1. Создаём каталог точки монтирования в корневой файловой системе:
   ```bash
   mkdir /raid
   ```

2. Делаем резервную копию системного файла `/etc/fstab`:
   ```bash
   cp /etc/fstab /etc/fstab.back
   ```

3. Добавляем запись автомонтирования массива:
   ```bash
   echo "/dev/md0 /raid ext4 defaults 0 0" >> /etc/fstab
   ```

![Добавление записи в fstab](/images/2027/m2-t2-fstab-echo.png)

#### 🔍 Разбор параметров строки fstab:
* **`/dev/md0`** — блочное устройство массива.
* **`/raid`** — каталог точки монтирования.
* **`ext4`** — тип файловой системы.
* **`defaults`** — стандартный набор параметров монтирования ядра (`rw`, `suid`, `dev`, `exec`, `auto`, `nouser`, `async`).
* **`0`** — отключение создания резервной копии утилитой `dump`.
* **`0`** — порядок проверки утилитой `fsck` при загрузке.

---

## Шаг 7. Проверка монтирования и свободного пространства

::: tip 💡 Важное правило системного администратора
Никогда не перезагружайте сервер вслепую после правки `/etc/fstab`! Всегда проверяйте применение файла командой `mount -av`.
:::

Применяем все записи из `/etc/fstab`:
```bash
mount -av
```

В выводе команды должна появиться строка:
```text
/raid                    : successfully mounted
```

![Проверка mount -av](/images/2027/m2-t2-mount-av.png)

Проверяем фактический размер и тип смонтированного тома:
```bash
df -T /raid
```

**Пример вывода:**
```text
Filesystem     Type  1K-blocks  Used Available Use% Mounted on
/dev/md0       ext4    2030488    48   1909856   1% /raid
```

![Проверка df -T /raid](/images/2027/m2-t2-df-raid.png)

*Общий полезный объём тома составляет около 2 Гб (~2030488 KB), что подтверждает успешное объединение двух дисков по 1 Гб в режиме RAID 0!* 🏆

## ⚡ Шпаргалка для быстрого выполнения на экзамене

```bash
# 1. Разметка дисков через parted:
parted -s /dev/sdb mklabel msdos mkpart primary 1MiB 100% set 1 raid on
parted -s /dev/sdc mklabel msdos mkpart primary 1MiB 100% set 1 raid on

# 2. Создание массива и фиксация:
mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/sdb1 /dev/sdc1
mdadm --detail --scan >> /etc/mdadm.conf

# 3. Форматирование и монтирование:
mkfs.ext4 /dev/md0
mkdir /raid
echo "/dev/md0 /raid ext4 defaults 0 0" >> /etc/fstab
mount -av
df -T /raid
```
