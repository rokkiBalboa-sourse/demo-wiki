*В процессе разработки*

В данном задании на всех виртуальных машинах инфраструктуры настраивается корректный часовой пояс (**Timezone**) и проверяется синхронизация системного времени.

Точное время и единый часовой пояс критически важны для:
* Корректного анализа и сопоставления системных журналов (`syslog`, `journalctl`) при расследовании инцидентов;
* Сроков действия цифровых сертификатов (TLS/SSL);
* Аутентификации и протоколов с временными метками (Kerberos, NTP, токены сессий);
* Сетевых баз данных и расписаний планировщика `cron` / `systemd-timers`.

## 1. Теоретическая справка: как устроено время в Linux

В операционных системах Linux сосуществуют два вида часов:
1. **Аппаратные часы (RTC / Hardware Clock)** — микросхема реального времени на материнской плате, питающаяся от батарейки (или виртуализируемая гипервизором Proxmox). Как правило, хранят время в шкале UTC.
2. **Системные часы (System Clock)** — внутреннее программное время ядра Linux. Начинает отсчёт при загрузке системы на основе RTC и далее поддерживается таймером процессора.

### Роль базы данных tzdata
Часовой пояс — это не просто смещение относительно нулевого меридиана (UTC), но и правила перехода на летнее/зимнее время, исторические изменения законов о времени. Вся эта информация хранится в специальной базе данных **IANA Time Zone Database**, которая в ALT Linux поставляется пакетом **`tzdata`**.

Все файлы часовых поясов находятся в каталоге `/usr/share/zoneinfo/`.

Текущий часовой пояс системы определяется символической ссылкой:
```bash
/etc/localtime → /usr/share/zoneinfo/Asia/Novosibirsk
```

### Утилита timedatectl
В современных дистрибутивах с systemd управление временем, часовыми поясами и демонами синхронизации осуществляется через унифицированную утилиту `timedatectl`.

## 2. Пошаговая настройка на хостах

Выполните следующие команды на каждом узле:

### Шаг 1. Установка и обновление базы данных часовых поясов
```bash
apt-get update && apt-get install tzdata -y
```

### Шаг 2. Установка требуемого часового пояса
В соответствии с заданием устанавливаем часовой пояс **Asia/Novosibirsk** (Новосибирск, UTC+7, Красноярское/Новосибирское время):
```bash
timedatectl set-timezone Asia/Novosibirsk
```

::: tip 💡 Как найти нужный часовой пояс на экзамене?
Если в вашем задании указан другой регион (например, Москва или Екатеринбург), найти точный системный идентификатор можно командой:
```bash
timedatectl list-timezones | grep -i moscow
# Вывод: Europe/Moscow

timedatectl list-timezones | grep -i yekaterinburg
# Вывод: Asia/Yekaterinburg
```
:::

---

### Шаг 3. Проверка текущих параметров времени

Запустите утилиту без аргументов:
```bash
timedatectl
```

**Пример корректного вывода:**
```text
               Local time: Wed 2026-09-23 18:15:30 +07
           Universal time: Wed 2026-09-23 11:15:30 UTC
                 RTC time: Wed 2026-09-23 11:15:30
                Time zone: Asia/Novosibirsk (+07, +0700)
System clock synchronized: yes
              NTP service: active
          RTC in local TZ: no
```

#### Разбор параметров вывода:
* **`Local time`** — местное время с учётом установленного часового пояса (`+07`).
* **`Universal time`** — мировое координированное время (UTC). Разница между Local и Universal составляет ровно 7 часов.
* **`RTC time`** — время, считанное из аппаратных часов виртуальной машины (RTC).
* **`Time zone`** — текущий активный часовой пояс (`Asia/Novosibirsk (+07, +0700)`).
* **`RTC in local TZ: no`** — аппаратные часы работают в UTC (стандарт для Linux-систем).

## ⚡ Шпаргалка для быстрого выполнения на экзамене

На каждом узле стенда:
```bash

timedatectl
```
