# Задание №9: Настройка DHCP-сервера для клиентов (HQ-CLI)

::: tip 📺 Видео-разбор задания
*В процессе разработки*
:::

В данном задании настраивается автоматическая выдача сетевых настроек для клиентских рабочих станций главного офиса (**HQ-CLI** в сегменте **VLAN 200**) с помощью сервиса `dhcp-server`, развёрнутого на маршрутизаторе **HQ-RTR**.

::: info 📍 Место выполнения
Все основные настройки выполняются на маршрутизаторе **HQ-RTR** (`hq-rtr.au-team.irpo`).
:::

---

## Шаг 1. Установка и настройка DHCP сервера на HQ-RTR

Выполните команды под пользователем `root` на машине **HQ-RTR**:

### 1. Устанавливаем пакет `dhcp-server`:
```bash
apt-get update && apt-get install dhcp-server -y
```

### 2. Конфигурируем файл `dhcpd.conf`:
Полностью заменяем содержимое конфигурационного файла пулом подсети VLAN 200:
```bash
nano /etc/dhcp/dhcpd.conf
```

```bash
subnet 192.168.200.0 netmask 255.255.255.240 {
  range 192.168.200.2 192.168.200.14;
  option domain-name-servers 192.168.100.2;
  option domain-name "au-team.irpo";
  option routers 192.168.200.1;
  default-lease-time 600;
  max-lease-time 7200;
}
```

::: tip 💡 Памятка по работе в Nano
* **Сохранить файл:** нажмите комбинацию <kbd>Ctrl</kbd> + <kbd>O</kbd>, затем подтвердите имя файла клавишей <kbd>Enter</kbd>.
* **Выйти из редактора:** нажмите <kbd>Ctrl</kbd> + <kbd>X</kbd> (при наличии несохранённых изменений нажмите <kbd>Y</kbd> для сохранения или <kbd>N</kbd> для отмены).
* **Быстро сохранить и выйти:** нажмите <kbd>Ctrl</kbd> + <kbd>X</kbd> → затем <kbd>Y</kbd> → затем <kbd>Enter</kbd>.
* **Поиск по файлу:** нажмите <kbd>Ctrl</kbd> + <kbd>W</kbd>, введите искомое слово и нажмите <kbd>Enter</kbd>.
* **Вырезать строку:** <kbd>Ctrl</kbd> + <kbd>K</kbd>, **вставить строку:** <kbd>Ctrl</kbd> + <kbd>U</kbd>.
:::

![Конфигурационный файл dhcpd.conf](/images/2027/m1-t9-dhcpd-conf.png)

#### 🔍 Разбор директив конфигурации:
* **`subnet ... netmask ...`** — объявляет подсеть и маску (`/28`), в которой работает данный пул адресов.
* **`range 192.168.200.2 192.168.200.14`** — диапазон динамической выдачи IP-клиентам. Адрес самого маршрутизатора (`192.168.200.1`) исключён из диапазона.
* **`option domain-name-servers 192.168.100.2`** — адрес корпоративного DNS-сервера (`HQ-SRV`), передаваемый клиентам.
* **`option domain-name "au-team.irpo"`** — суффикс доменного поиска.
* **`option routers 192.168.200.1`** — шлюз по умолчанию (виртуальный интерфейс `vlan200` на `HQ-RTR`).
* **`default-lease-time`, `max-lease-time`** — стандартное и максимальное время аренды IP-адреса в секундах.

### 3. Активируем и запускаем службу:
```bash
systemctl enable --now dhcpd
systemctl restart dhcpd
```

---

## Шаг 2. Проверка работы DHCP сервера (HQ-CLI)

Перейдите на рабочую станцию **HQ-CLI**:

### 1. Перезапускаем сетевую службу:
```bash
systemctl restart network
```
*(При запросе авторизации введите пароль администратора: `toor`)*

### 2. Проверяем полученный IP-адрес:
```bash
ip -c --br a
```
*Интерфейс должен получить адрес из диапазона `192.168.200.2 - 192.168.200.14`.*

### 3. Проверяем доступность сети Интернет:
```bash
ping -c4 77.88.8.8
```

## ⚡ Шпаргалка для быстрого выполнения на экзамене

На **HQ-RTR**:
```bash
apt-get update && apt-get install dhcp-server -y
cat << 'EOF' > /etc/dhcp/dhcpd.conf
subnet 192.168.200.0 netmask 255.255.255.240 {
  range 192.168.200.2 192.168.200.14;
  option domain-name-servers 192.168.100.2;
  option domain-name "au-team.irpo";
  option routers 192.168.200.1;
  default-lease-time 600;
  max-lease-time 7200;
}
EOF
systemctl enable --now dhcpd
systemctl restart dhcpd
```
